# 달려라 고니고니

왕관 쓴 고니 🦢 가 주인공인 웹 아케이드 게임입니다. 고전 아케이드 **너구리(Ponpoko,
1982)** 의 조작 방식을 바탕으로 만들었고, HTML5 Canvas + 바닐라 JavaScript(ES 모듈)로만
작성했습니다. 빌드 과정이나 의존성이 없습니다.

## 플레이 방법

고니 🦢 를 조작해 넝쿨(사다리)을 타고 층을 오르내리며 과일 🍒 을 절반 이상 먹고,
게 🦀 를 피하고 장애물 🌵 은 점프로 넘어 좌측 상단 갈대숲 🌾 으로 들어가면 스테이지 클리어입니다.

| 키 | 동작 |
| --- | --- |
| ← → (또는 A / D) | 좌우 이동 |
| ↑ ↓ (또는 W / S) | 넝쿨 오르내리기 |
| Enter / Space | 시작 · 다시 하기 |

## 실행

ES 모듈은 `file://` 로 열면 동작하지 않으므로 로컬 정적 서버가 필요합니다.
저장소 루트에서:

```bash
python3 -m http.server 5173
```

그런 다음 브라우저에서 `http://localhost:5173/` 를 엽니다.

## 구조

```
index.html      화면 레이아웃 · HUD · 오버레이
css/style.css   레트로 스타일
js/config.js    타일 크기 · 속도 · 중력 등 상수
js/level.js     ASCII 맵 파서 (레벨 = 데이터)
js/player.js    고니 이동/등반 물리
js/enemy.js     게(적) 순찰 AI
js/game.js      게임 상태 · 루프 · 충돌 · 렌더링
js/input.js     키보드 입력
js/main.js      진입점
```
